# Runner background assets

`chromium-offline-sprite.png` is the original Chromium offline game sprite sheet:
https://raw.githubusercontent.com/chromium/chromium/main/components/neterror/resources/images/default_100_percent/offline/100-offline-sprite.png

Copyright The Chromium Authors. See `CHROMIUM-LICENSE.txt` for the BSD license.
Downloaded 2026-10-05. The bitmap is unchanged; CSS displays the original running
frames at 2x scale and recolors the artwork white. This is a decorative animation,
not an interactive game; jumping and collision handling are intentionally absent.
